🚀 INICIO RÁPIDO (Desde raíz del proyecto)
─────────────────────────────────────────
1. Desde la raíz:
   ./run_choch_bos.sh

2. Desde la carpeta de estrategia:
   cd strategies/choch_bos/scripts
   ./start_trading.sh

3. Comando directo:
   freqtrade.exe trade \
     --strategy CHoCHBOSStrategy \
     --config strategies/choch_bos/configs/config_choch_bos_live.json \
     --timeframe 15m

⚙️ CONFIGURACIÓN
────────────────
1. Edita: strategies/choch_bos/configs/config_choch_bos_live.json
2. Cambia API keys en sección "exchange"
3. Para cambiar exchange, edita "name" y "pair_whitelist"
   - Binance Futures: ya configurado (pares con :USDT)
   - Binance Spot: cambiar a pares sin :USDT
   - Hyperliquid: cambiar name a "hyperliquid", usar :USDC
